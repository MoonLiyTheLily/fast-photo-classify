# 速理 Fastphoto

一款面向 Android 的本地照片整理应用，用滑动选择和拖放操作，把照片整理到手机上的真实相册目录。

采用 Flutter 构建界面，通过 Kotlin 与 Android MediaStore 交互。支持 Android 11 及以上版本，当前版本为 `0.3.4`。

安装后显示的名称跟随系统语言：中文显示“速理”，英文及其他语言显示“Fastphoto”。首页标题与界面语言保持一致。

界面支持中文和英文，默认跟随系统，也可在设置中选择“中文”或“English”。语言选择会保存到本机。照片文件名、相册名和用户保存的方案名保留原样。

## 功能

- **快速选照片**：长按进入选择，连续滑动批量选取，反向滑动撤回本轮新增选择；也可按日期整组选取。
- **拖放整理**：长按已选照片，将照片堆拖入目标相册；支持相册列表滚动、边缘自动滚动，以及“放入相册”按钮操作。
- **移动与复制**：默认移动原图，也可切换为复制。移动请求通过系统授权，同名文件不会被覆盖。
- **整理范围与方案**：选择源相册和目标相册，保存常用方案；通过归类规则区分“待整理”和“已归类”。
- **相册浏览**：搜索相册，按中文拼音或最近更新排序，新建相册，浏览指定目录。
- **照片预览**：双指或双击缩放，上滑查看详情，下滑退出；可查看拍摄位置并打开地图。
- **个性化设置**：中文、英文或跟随系统语言，明亮、深色或跟随系统主题，网格密度、日期分组，以及四个方向的整理面板。

## 使用方式

1. 打开应用并授予照片访问权限。Android 14 及以上也支持只授权部分照片。
2. 长按一张未选照片，按住滑动以连续选取；松手后可通过照片右上角的复选框调整选择。
3. 长按任意已选照片，将照片堆拖入目标相册并松手；也可点击底部“放入相册”。
4. 移动照片时，根据系统提示确认授权。取消拖放或拒绝授权后，选择会保留。

长按“待整理”设置源相册，长按“已归类”设置目标相册。所有相册默认未归类，需要在“归类规则”中明确指定；选择源或目标不会改变归类状态。常用整理范围可手动保存为方案。

## 照片与隐私

照片浏览和整理在本机进行，应用不上传照片，也不获取实时定位。读取照片范围取决于系统授予的权限。

拍摄位置功能需要单独开启并授权。查询地名会调用手机系统的地理编码服务，打开地图会将照片坐标传给地图服务；这些操作可能使用网络。离线或地名查询不可用时，仍可显示已读取的经纬度。

## 多语言维护

Flutter 界面使用官方 ARB / `gen_l10n` 方案，翻译资源位于 [lib/l10n/](lib/l10n/)，生成配置位于 [l10n.yaml](l10n.yaml)。新增语言时添加对应的 `app_<语言代码>.arb` 文件，并运行 `flutter gen-l10n`；支持的语言列表会自动生成。`flutter pub get` 和构建也会生成本地化代码，生成目录不提交到仓库。未支持的语言默认显示英文。

新增界面文案时，在 `app_en.arb` 中定义键名，在其他 ARB 文件中添加翻译，通过 `AppLocalizations` 读取。带数量或变量的文案使用占位符和复数规则；日期与星期通过 `intl` 按语言格式化。原生照片接口返回的错误标识也由 Flutter 的翻译资源转换为界面提示。

如果要把新增语言加入设置中的手动选择菜单，还需扩展 `AppLanguage` 及语言选择项；新增翻译文件后，该语言即可用于“跟随系统”模式。

Android 安装后显示的名称由原生资源控制，需要同时在对应的 `android/app/src/main/res/values-<语言代码>/strings.xml` 中添加 `app_name`。默认名称在 [values/strings.xml](android/app/src/main/res/values/strings.xml) 中，中文名称在 [values-zh/strings.xml](android/app/src/main/res/values-zh/strings.xml) 和 [繁体中文资源](android/app/src/main/res/values-b+zh+Hant/strings.xml) 中。

## 当前限制

- 当前仅支持 Android 和照片，不包含视频、云相册、按内容去重、批量重命名或删除功能。
- 整理目标限于可写入的 `Pictures/` 和 `DCIM/` 目录。`Download/` 等其他可读目录可以浏览或作为源相册。
- 跨存储卷移动暂不支持，可改用复制。复制保留原图，失败时会清理未完成的副本。
- 归类由相册规则决定；应用可以记录自身复制产生的关系，但不会推断其他软件创建的副本关系。
- 大图预览会限制解码尺寸以控制内存占用，原文件不受影响。
- 不同厂商的权限提示、地名服务和外置存储行为可能有所不同。
